# 小伙伴桌宠 9.0（智能陪伴修复版）

7.0 的重点是提升“理解上下文、回应情绪、帮助处理事情”的智能部分，同时让本地数据共享保持透明、可控。

## 本次新增与修复

### 0. 修复编译报错
- 将聊天页模式按钮的布局参数改为显式 Android 类名，并拆分按钮创建与添加步骤，针对之前 GitHub Actions 报出的 `ChatActivity.kt:113 Unresolved reference LayoutParams` 做了明确修复。
- 已检查源码包结构；当前运行环境无法解析 `services.gradle.org`，所以 Gradle 8.9 分发包无法下载；本次不能在这里完成 APK 编译。请用仓库中的 GitHub Actions 确认最终构建。

### 0.1 对话上下文更稳
- 将“继续 / 然后呢 / 第 2 点”等短追问与完整问题区分，减少把独立问题误判成追问的情况。
- 追问编号时，尝试引用上一条回复中对应的编号条目。
- 新增可持续的对话偏好：倾听模式、直接方案模式、普通交流模式；偏好保存在本地。
- 独立 AI 的系统提示也会读取当前对话偏好。
- 仍优先处理安全相关表达，避免切换聊天风格的口令覆盖安全回应。

## 本次新增

### 1. 本地对话理解增强
- 新增轻量级本地对话分析器，可识别常见的情绪表达、追问、建议请求、任务规划、边界表达、状态查询和回忆查询。
- 对“继续、那怎么办、为什么、还有吗”等短追问，尝试结合最近的聊天上下文，而不是每次都从头回答。
- 用户表示不想聊或想独处时，优先尊重边界，不继续追问。
- 支持“帮我规划”等请求，生成可执行的小步骤。
- 支持根据本机已保存聊天生成简要复盘；只总结实际保存的记录，不声称知道记录之外的事情。
- 本地模式仍是规则与上下文分析，不是完整的大语言模型；不需要网络或 API Key。

### 2. 心情记录可在聊天中完成
- 发送“记录心情：今天有点累，但完成了一件重要的事”即可保存一条本地心情日记。
- 根据明确写出的内容进行简单的 1–5 档心情分类。
- 不会自动把普通聊天内容写进心情日记。

### 3. 独立 AI 的角色与上下文优化
- 将角色名字、好感度、关系、心情、精力、饥饿值与所选性格整合进系统提示。
- 改善建议、倾听、任务拆分和短追问的回复规则。
- 新增“允许独立 AI 读取我主动保存的回忆”开关，默认关闭。
- 未开启时，已保存回忆只在手机本地使用；开启后，最多选取最近 8 条明确保存的回忆，随独立 AI 请求发送给你配置的服务商。
- 之前保存的本地聊天记录仍不会自动作为 API 上下文发送。

### 4. 快捷入口扩充
- 新增“帮我规划”“继续刚才”“复盘今天”“我有点焦虑”“你记得什么”等快捷短语。
- 增加“你能做什么”能力说明与更贴近上下文的本地回复。

## 继续保留

- Android 桌面悬浮宠物：单击互动、双击桌面对话、长按菜单、拖动移动。
- 4 套主题、3 种性格、动作演示与日常主动反应。
- 好感度、关系称号、心情、精力、饥饿感、连续陪伴天数、星星币、每日签到、礼物、回忆本与成就。
- 本地聊天记录、心情日记、专注计时和数据备份/恢复。
- 免费本地陪聊、ChatGPT 网页入口、兼容 OpenAI Chat Completions 的独立 AI 接口。

## 隐私说明

- 心情日记、聊天记录和回忆本默认保存在设备本地。
- 本地聊天模式不联网。
- 独立 AI 只会发送当前 API 会话中的消息与上下文；保存的本地聊天记录不会自动发送。
- 已保存回忆的 AI 共享开关默认关闭，需手动开启。不要输入密码、支付信息等敏感内容。
